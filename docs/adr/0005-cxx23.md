# 0005. Use C++23, with GCC 14 and Clang 18 as the minimum

- **Status:** Proposed
- **Date:** 2026-10-18
- **Deciders:** mb6ockatf, d1mark2
- **Issue:** #115

## Context

The language level and the oldest supported compiler decide which features the
code may use and which distributions can build Orange. CI builds with the
minimum and the newest supported compiler.

Questions this ADR must answer:

- [ ] Why C++23 rather than C++20 (`std::expected`, `std::print`, deducing
  `this`).
- [ ] Why GCC 14 / Clang 18 with libstdc++ 14 as the minimum, and which C++23
  features that minimum rules out (`std::flat_map`, `import std`, modules).
- [ ] Why `ORANGE_CXX23` checks features instead of the `-std=` option.
- [ ] When the minimum is raised, and who decides.

## Decision

We write C++23. The minimum compilers are GCC 14, and Clang 18 with libstdc++
14; `ORANGE_CXX23` checks for the features we use rather than for a `-std=`
option.
